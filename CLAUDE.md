# ModNest

- **Adding or updating a mod in the catalog?** Follow [AGENTS.md](AGENTS.md): one `submissions/<id>.json` file in a pull request. Don't edit `registry/registry.json` by hand for that.
- Working on the app itself: the engine is `core/` (crate `modnest-core`, no UI; tests in `core/tests`). The shipped app (from 0.3.0) is `native/` (GPUI, no WebView); `scripts/package-native.ps1` builds its signed installer. The older WebView app is `src-tauri/` (thin Tauri layer, also holds the installer config and icons) + `ui/`. Screenshots of the WebView UI that `native/` matches are in `native/reference/`. Building `native/` on the GNU toolchain needs `GPUI_FXC_PATH` pointing at `tools/fxc-shim`. See [README.md](README.md) for building (set `CARGO_TARGET_DIR` to a path without spaces on the MinGW toolchain) and `cargo test -p modnest-core`.
